Open Source Beginner Checklist

Print this page and check off each step as you go.

Tip: press Ctrl+P (or Cmd+P) to print. Headers and navigation are hidden when printed.

Back to guide

Getting started

  • Created a GitHub account
  • Verified my email address on GitHub

Finding a project

  • Searched GitHub for a project that interests me
  • Looked for beginner-friendly signs (README, CONTRIBUTING, `good first issue` labels)
  • Read the project's README
  • Checked when the project was last active

Installing software

  • Downloaded a release, OR
  • Installed from source following the README
  • Got the software running on my computer

Reporting an issue (optional but encouraged)

  • Searched existing issues for the same problem
  • Gathered details (what I did, what happened, my operating system)
  • Opened a new issue OR added a comment to an existing one

Making your first pull request

  • Found a small fix (typo, docs, example)
  • Forked the project
  • Made my change on a new branch
  • Opened a pull request with a clear title and description
  • Replied to any review comments

Done!

You have used and contributed to open-source software. Congratulations!
