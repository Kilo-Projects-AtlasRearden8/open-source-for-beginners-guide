# Finding Open-Source Projects

Open-source projects live all over the internet, but the best place to start is
[GitHub](https://github.com). GitHub is a website where people host code, track
issues, and work together. It is free to use.

## Step 1: Make a GitHub account

1. Go to github.com and click **Sign up**.
2. Follow the prompts to create your account.
3. Verify your email address.

You need an account to comment on issues or send pull requests. You do not need
an account just to browse or download.

## Step 2: Search for projects

Use the search bar at the top of GitHub. Try searches like:

- "beginner friendly"
- "good first issue"
- "first-timers-only"
- A topic you care about, like "budget", "chess", or "AI"

## Step 3: Look for beginner-friendly signs

A project is likely welcoming to beginners if it has:

- A `README.md` file that explains what the project does
- A `CONTRIBUTING.md` file that explains how to contribute
- Labels like `good first issue` or `beginner-friendly`
- Recent activity (commits or comments in the last few months)
- Clear instructions for installing and running the project

## Step 4: Look at the README before doing anything

The README usually tells you:

- What the project does
- How to install it
- How to run it
- How to contribute

Read it first. It will save you time.

## Where else to look

- [github.com/explore](https://github.com/explore) — GitHub's project collections
- [firsttimersonly.com](https://www.firsttimersonly.com/) — beginner-friendly issues
- [up-for-grabs.net](https://up-for-grabs.net/) — projects with starter tasks
