A plain-English guide to finding, installing, and contributing to open-source software on GitHub.

Introduction

Open-source software is software anyone can use, study, change, and share. When you use open source, you join a community of people building tools together — and you are welcome to join, too.

You do not need to be a programmer. You do not need to know the command line. If you can use a web browser, you can follow this guide.

Finding Open-Source Projects

The best place to start is GitHub, a free website where people host code, track issues, and work together.

1. Make a GitHub account

  1. Go to github.com and click Sign up.
  2. Follow the prompts to create your account.
  3. Verify your email address.

You need an account to comment on issues or send pull requests. You do not need an account just to browse or download.

2. Search for projects

Use the search bar at the top of GitHub. Try searches like "beginner friendly", "good first issue", or a topic you care about, like budget, chess, or AI.

3. Look for beginner-friendly signs

  • A README.md file explaining what the project does
  • A CONTRIBUTING.md file explaining how to contribute
  • Labels like good first issue or beginner-friendly
  • Recent activity in the last few months
  • Clear install and run instructions

4. Read the README first

The README tells you what the project does, how to install it, how to run it, and how to contribute. Read it before doing anything else.

Installing Open-Source Software

Option A: Download a release (easiest)

  1. Go to the project's GitHub page.
  2. Look for the Releases section or click Releases in the top menu.
  3. Find the latest release.
  4. Download the file for your computer:
    • Windows: .exe or .msi
    • Mac: .dmg or .pkg
    • Linux: .AppImage, .deb, or source tarball
  5. Open the file and follow the installer.

Option B: Install from source code

Follow the project's README step by step. Common commands you might see:

git clone https://github.com/owner/repo.git
cd repo
npm install          # or: pip install -r requirements.txt
npm start            # or: python main.py

If you get stuck, search the project's Issues tab for your error message, or open a new issue.

Reporting Issues

An "issue" is a report of a problem, a question, or a feature request. Reporting issues is one of the most helpful things a beginner can do — no coding required.

Before you open an issue

  • Search the project's Issues tab for the same problem.
  • If you find a match, comment that you have the same problem instead of opening a new one.
  • Gather details: what you did, what happened, what you expected, and your operating system.

How to open an issue on GitHub

  1. Go to the project's GitHub page.
  2. Click the Issues tab.
  3. Click New issue.
  4. Give it a clear title.
  5. Describe what you did, what happened, what you expected, your operating system, and any error messages.
  6. Click Submit new issue.

Making Your First Pull Request

A "pull request" (PR) is how you suggest changes to a project. This walkthrough uses GitHub's website — no command line required.

1. Fork the project

Go to the project's GitHub page, click Fork in the top right, and choose your account. GitHub copies the project to your account.

2. Find something to fix

Good first contributions: fixing a typo in the README, adding a missing installation step, or translating a document. Look for issues labeled good first issue or beginner-friendly.

3. Edit a file on GitHub

  1. In your fork, find the file you want to change.
  2. Click the pencil icon (Edit this file).
  3. Make your change.
  4. Choose Create a new branch and give it a name, like fix-readme-typo.
  5. Click Commit changes.

4. Open a pull request

  1. Click Compare & pull request (or go to your fork → Contribute → Open pull request).
  2. Give the PR a clear title and describe what you changed.
  3. Click Create pull request.

5. Wait for review

A maintainer may comment or request changes. Reply politely. If they merge your PR, congratulations — you are an open-source contributor!
