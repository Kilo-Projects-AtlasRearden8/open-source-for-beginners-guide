# Open Source for Beginners

A plain-English guide to finding, installing, and contributing to open-source
software on GitHub.

## Who this is for

You do not need to be a programmer. You do not need to know the command line.
If you can use a web browser, you can follow this guide.

Open-source software is software anyone can use, study, change, and share. When
you use open source, you join a community of people building tools together —
and you are welcome to join, too.

## What you will learn

1. [Finding projects](finding-projects.md) — how to find a project on GitHub
2. [Installing software](installing.md) — how to install and run it
3. [Reporting issues](reporting-issues.md) — how to tell a project about a problem
4. [Making your first pull request](first-pull-request.md) — how to contribute a fix

There is also a [printable checklist](checklist.md) you can print and check off
as you go.
