# Open Source for Beginners

A plain-English beginner manual for using and contributing to open-source
software. GitHub-focused. Includes a printable checklist.

## What's inside

- **docs/** — Beginner manual: finding projects, installing open-source software,
  reporting issues, and making your first pull request. Written in plain English.
- **static/** — Static HTML version of the manual with a printable checklist.
- **LICENSE** — MIT License. Copyright (c) 2026 Asdale Dynamics, LLC.

## Who this is for

Anyone new to open source. No coding experience required. If you can use a web
browser, you can use this guide.
