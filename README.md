# Open Source for Beginners

A plain-English beginner manual for using and contributing to open-source
software on GitHub. Includes a printable checklist.

## Who this is for

Anyone new to open source. You do not need to be a programmer. You do not need
to know the command line. If you can use a web browser, you can use this guide.

Written in plain English, step by step, never condescending — like a friend
explaining it to you.

## What's inside

| Section | What it covers |
|---------|----------------|
| `docs/intro.md` | What open source is and what you'll learn |
| `docs/finding-projects.md` | How to find a beginner-friendly project on GitHub |
| `docs/installing.md` | How to install and run open-source software |
| `docs/reporting-issues.md` | How to report a problem or suggest a feature |
| `docs/first-pull-request.md` | How to make your first pull request |
| `docs/checklist.md` | Printable checklist to track your progress |
| `static/index.html` | Full manual as a static web page |
| `static/checklist.html` | Printable checklist as a static web page |

## How to use this guide

1. Read [`docs/intro.md`](docs/intro.md), or open
   [`static/index.html`](static/index.html) in your web browser.
2. Work through each section in order.
3. Print [`docs/checklist.md`](docs/checklist.md) or
   [`static/checklist.html`](static/checklist.html) and check off each step as
   you go.
